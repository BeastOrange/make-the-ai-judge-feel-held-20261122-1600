This repository contains the entry submission code for the make-the-ai-judge-feel-held-20261122-1600 competition. It runs deterministically to write the entry text to the designated output path.

## Run it

Execute the script with Python 3:

```bash
python3 main.py
```

The output will be written to `/output/entry.txt` (or the path set in the `ENTRY_OUTPUT` environment variable).
